# Study Room - Junaid (Flutter Android APK Project)

এই প্রজেক্টে আপনার সম্পূর্ণ **Study Room (`index.html`)** ওয়েবসাইটটি **Flutter Native YouTube & Video Downloader Engine (`youtube_explode_dart` + Local HTTP Range Streaming Server)**-এর সাথে যুক্ত করা হয়েছে।

## কী কী নতুন সুবিধা যুক্ত হয়েছে?
১. **এক ক্লিকে সরাসরি YouTube ও ক্লাস ভিডিও ডাউনলোড:** যেকোনো ক্লাসের ভিডিও প্লেয়ারের নিচে নতুন **“ডাউনলোড”** বাটন যুক্ত করা হয়েছে। এতে ক্লিক করলে সরাসরি অ্যাপের ভেতরেই লাইভ প্রগ্রেস বার (`0% - 100%`) দেখিয়ে ভিডিওটি অফলাইনে ফোনের অ্যাপ মেমোরিতে সেভ হয়ে যাবে।
২. **ইন্টারনেট ছাড়া অফলাইন প্লেব্যাক (স্পিড কন্ট্রোল ও প্রগ্রেসসহ):** একবার ডাউনলোড হয়ে গেলে ফোনের ডাটা/ওয়াইফাই বন্ধ থাকলেও ক্লাসটি অ্যাপের নিজস্ব কাস্টম প্লেয়ারে (`1x` থেকে `3x` স্পিড, `10s` ডাবল-ট্যাপ স্কিপ এবং স্টাডি টাইমারসহ) চলবে।
৩. **Saved সেকশনে “অফলাইন ভিডিও” ট্যাব:** `Saved` মেনুতে নতুন **“অফলাইন ভিডিও”** ট্যাব যুক্ত করা হয়েছে, যেখানে সব ডাউনলোড করা ক্লাস এক জায়গায় দেখা যাবে এবং কাজ শেষে ডিলিট করে ফোনের মেমোরি খালি করা যাবে।

## কীভাবে APK তৈরি করবেন? (২টি সহজ পদ্ধতি)

### পদ্ধতি ১: কম্পিউটার ছাড়া শুধু মোবাইল দিয়েই ফ্রি APK বিল্ড (GitHub Actions দিয়ে)
আপনার কম্পিউটারে Flutter বা Android Studio ইনস্টল করা না থাকলেও আপনি বিনামূল্যে GitHub থেকে `.apk` ফাইলটি তৈরি করে ডাউনলোড করতে পারবেন:
1. GitHub-এ একটি নতুন Repository খুলে এই ZIP ফাইলের ভেতরের সব ফাইল সেখানে আপলোড করুন।
2. Repository-এর **Actions** ট্যাবে যান -> **Build Study Room Android APK** ওয়ার্কফ্লোটি অটোমেটিক চালু হবে (অথবা `Run workflow` বাটনে ক্লিক করুন)।
3. ৩–৪ মিনিটের মধ্যে বিল্ড শেষ হলে নিচে **Artifacts** সেকশন থেকে **`Study-Room-Junaid-Release-APK`** ডাউনলোড করলেই ভেতরে `app-release.apk` পেয়ে যাবেন!

### পদ্ধতি ২: কম্পিউটারে Flutter দিয়ে সরাসরি APK বিল্ড
আপনার কম্পিউটারে Flutter SDK থাকলে ফোল্ডারটি আনজিপ করে টার্মিনালে নিচের কমান্ডগুলো রান করুন:
```bash
flutter create --platforms=android --org com.junaid.studyroom .
flutter pub get
flutter build apk --release
```
বিল্ড শেষ হলে `build/app/outputs/flutter-apk/app-release.apk` ফাইলটি ফোনে ইনস্টল করে নিন।
